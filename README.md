Usage

    uv run python download_speed.py *ссылка на изображение*

Единицы измерения

Среднее время запроса выводится в секундах (s), общий объём — в мебибайтах (MiB), скорость — в мебибайтах в секунду (MiB/s). 1 MiB = 1 048 576 байт. Скорость рассчитывается как общий объём полностью прочитанных ответов, делённый на суммарное время 10 последовательных запросов.
